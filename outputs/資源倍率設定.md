# Rust 資源倍率設定

更新日期：2026-09-26。伺服器位置：`D:\RustServer`。

目前設定為 **3 倍**：

| 來源 | 效果 | 插件 |
|---|---|---|
| 敲石頭與砍樹 | 採集所得及採集獎勵 ×3 | GatherRates 0.2.0 |
| 撿拾地上的天然資源 | 所得數量 ×3 | GatherRates 0.2.0 |
| 新生成的寶箱 | 可堆疊物品數量 ×3 | GatherRates 0.2.0 |
| 回收機 | 回收產物數量 ×3，消耗的投入品數量維持原本規則 | Recycle Manager 2.2.1 |

倍率針對**取得數量**，不加快回收速度，也不增加石頭或樹木本身的資源總量。寶箱不會把槍械、防具等不可堆疊物品複製成三件；既有且已生成的寶箱維持原數量，等它們重新生成後才使用新倍率。採礦場、挖掘機、農作物、任務獎勵與玩家交易目前不在此設定中。

兩個設定檔位置：

- `D:\RustServer\server\oxide\config\GatherRates.json`：石頭／樹木、地上資源及新生成寶箱，三個數值皆為 `3.0`。
- `D:\RustServer\server\oxide\config\RecycleManager.json`：`Output multipliers` 下的 `Default multiplier` 為 `3.0`。

修改倍率時，先備份設定檔，編輯數值，接著在伺服器主控台執行 `oxide.reload GatherRates` 或 `oxide.reload RecycleManager`。採集插件原始碼在 `D:\RustServer\plugins\src\GatherRates.cs`。回收機插件是 uMod 的 [Recycle Manager](https://umod.org/plugins/recycle-manager)，原始碼副本放在本機 `plugins\src`（第三方作品，未放進 GitHub repo，請從 uMod 下載）；更新此第三方插件時要保留上述設定檔。

已驗證兩個插件成功編譯、載入，設定檔數值正確。尚未由遊戲客戶端實際敲礦、開箱或使用回收機比較數量；請在遊戲內用一次採集、剛重新生成的箱子，以及投入一件可回收物品做最後驗證。若同時安裝其他會更改相同來源的倍率插件，效果可能疊乘，需再檢查。

技術依據：[Oxide 採集事件](https://docs.oxidemod.com/hooks/resource/OnDispenserGather)、[地上資源事件](https://docs.oxidemod.com/hooks/resource/OnCollectiblePickedup)、[寶箱生成事件](https://docs.oxidemod.com/hooks/resource/OnLootSpawn)、[Recycle Manager 產出倍率](https://umod.org/plugins/recycle-manager)。
